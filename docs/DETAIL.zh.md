# 会话专注

“会话专注”添加独立的近期会话紧凑视图，不修改 DSH 内置列表模式。

## 使用方法

点击侧栏底部的 **专注**。时间按钮可筛选最近 3 小时、6 小时、1 天、3 天或全部会话。`▦` 按 Workspace 分组，`Aa` 显示由项目路径最后两个文件夹组成的稳定彩色标签。

会话按最近活动时间排序；启用分组后，项目也按其中最新会话排序。卡片显示标题、项目和紧凑活动时间，并用蓝、橙、黄、青、绿背景表示当前状态。模型回复完成但尚未打开时，卡片会增加独立的 **未读** 行。

点击卡片打开会话，操作按钮打开标准 DSH 会话菜单，顶部箭头返回内置列表。模式、时间筛选、分组和标签设置保存在当前浏览器中。

## 限制

DSH 未在内置列表标题中提供公开扩展位置，因此入口位于侧栏底部。打开会话时 DSH 会清除未读完成状态；完整刷新客户端页面后，该状态不会保留。
